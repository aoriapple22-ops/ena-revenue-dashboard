# ENA 신성장센터 매출 대시보드

ENA 신성장센터의 **신사업개발팀**과 **디지털사업팀** 실적을 한 화면에서 조회하는 사내 대시보드입니다.

센터장·임원이 매출 현황이나 전년 대비 추이를 확인하려면 그때마다 실무팀에 자료를 요청해야 했고, 실무팀은 흩어진 엑셀을 매번 취합해야 했습니다. 이 대시보드는 그 과정을 없애고 원하는 시점에 직접 조회할 수 있게 합니다.

> **POC 단계**입니다. 기능과 데이터 범위가 계속 바뀔 수 있습니다.

---

## 화면

| 경로 | 설명 |
|---|---|
| `/` | 연도별 요약. 팀별 매출·목표·달성률 |
| `/nsd` | 신사업개발팀 — 사업군별 월별/연간 매출, 전년 대비 |
| `/digital` | 디지털사업팀 — 채널별 / 월별 통합 / 매출구분별 |
| `/program` | 프로그램별 성과 (ENA 채널 한정) |
| `/target` | 목표 대비 달성률 — 항목별·월별 |

## 주요 기능

- **신사업개발팀 매출** — 건기식 / 브랜디드 / 기타사업(협찬) / 커머스 4개 사업군, 계약 기준
- **디지털 채널별 실적** — 조회수·구독자 증감·총매출·배분액·순매출
- **프로그램별 성과** — 타이틀별 조회수·예상수익·시청률(2049/가구)
- **목표 대비 달성률** — 연간 목표와 실적 비교
- **주간 갱신** — 정해진 엑셀 양식에 실적을 추가하면 반영

## 기술 스택

- **Next.js 14** (App Router) — 화면과 서버 코드를 한 프로젝트에서 처리
- **Supabase** (PostgreSQL) — 실적 데이터 저장, 읽기 전용 RLS
- **Vercel** — 배포

## 데이터 설계에서 지키는 규칙

실제 운영 자료를 다루며 발견한 함정들을 코드와 스키마에 규칙으로 못박아 두었습니다.

**① 매출 기준을 섞지 않는다**
같은 매출도 `계약` / `계산서` / `회계(편성)` 기준에 따라 금액이 달라집니다. 기준이 섞이면 합계가 맞지 않으므로 대시보드는 **계약 기준으로 통일**합니다.

**② 기준이 다른 수치를 합산하지 않는다**
프로그램별 성과는 **ENA 채널 한정**이고, 채널별 매출은 전 채널 기준입니다. 두 값을 더하면 틀린 숫자가 나오므로 화면을 분리하고 배지로 명시합니다.

**③ 순매출과 총매출을 구분한다**
협력업체 재방 채널은 총매출에서 배분액을 차감해야 실제 수익이 됩니다.
`순매출 = 총매출 + 배분액` (배분액은 음수)

**④ 실적과 추정을 구분한다**
원본 자료에는 확정 실적과 추정치가 섞여 있습니다. 모든 행이 `실적`/`추정`을 갖고, 화면에 추정 표시가 붙습니다.

**⑤ 표기를 표준명으로 통일한다**
같은 대상이 자료마다 다르게 적혀 있으면 집계가 쪼개집니다. 마스터 코드로 통일합니다.

| 표준명 | 다른 표기 |
|---|---|
| ENA K-POP | KPOPUP, 케이팝업차트쇼 |
| kt쇼츠채널 | 쇼츠채널, 케이티 쇼츠채널 |
| 두부우 | 두우부 |
| 둠칫 | 둠칫(랩소디) |

**⑥ 금액 단위는 원으로 고정한다**
원 단위와 억원 단위가 섞이는 것을 막기 위해 저장은 항상 원 단위 정수, 표시할 때만 억 단위로 환산합니다.

## 접근 보호

사내 재무 자료를 다루므로 **공통 비밀번호로 전체 페이지를 보호**합니다.

- `middleware.js`가 모든 경로를 가로채고, 인증되지 않으면 `/login`으로 보냅니다
- 비밀번호가 맞으면 **HMAC-SHA256으로 서명한 토큰**을 HttpOnly 쿠키에 담습니다 (유효기간 12시간)
- 서명이 없거나 위조된 쿠키, 만료된 쿠키는 모두 거부됩니다
- 비밀번호는 서버에서만 읽는 `SITE_PASSWORD` 환경 변수입니다 (`NEXT_PUBLIC_` 아님 → 브라우저에 노출되지 않음)
- `SITE_PASSWORD`가 비어 있으면 보호가 꺼집니다 (로컬 개발 편의)

비밀번호를 바꾸려면 환경 변수만 교체하고 재배포하면 됩니다. 코드 수정은 필요 없습니다.

> 공통 비밀번호 방식이라 **누가 접속했는지는 알 수 없습니다.** 사용자별 계정과 감사 로그가 필요해지면 별도 인증 도입이 필요합니다.

## 이번 범위에서 만들지 않은 것

- 대시보드에서 데이터를 직접 입력·수정하는 기능 (조회 전용)
- 사용자별 계정 / 권한별 접근 제어 (공통 비밀번호만 적용)
- 유튜브 API 등 외부 데이터 자동 연동 (주간 엑셀로 수동 갱신)
- 매출 예측이나 AI 기반 분석
